# 这套系统现在能稳定赚钱吗?—— 系统性辩论 + 诚实结论

**日期**: 2026-07-01
**方法**: 验证当前代码(非复述旧审计)+ 修好引擎重跑 + DSR/PBO 过拟合闸 + 成熟量化系统对照
**一句话结论**: **股票 long-only 不能稳定赚钱(恒等式:收益=不可对冲的股票 beta)。最接近的载体是可转债(债底保底,数据经官方指数交叉验证可信,月度相关 0.909)——但经 6-agent 对抗式验证,"稳定"是 regime 依赖的叙事过拟合:10 年 +7.57% 里剔掉 2019/21/25 三个牛年只剩 +0.74%,当前估值极贵+债底被 2024 违约削弱+可交易券缩 42%+容量墙 1~3 亿,前瞻现实预期仅小资金 ~+4.5%、大资金转负。诚实结论:不值得为这点 regime 依赖的被动 beta 冒违约+容量+过拟合三重险,被动持有官方可转债指数更优。真正的交付是那套能拦住这类过度乐观的 DSR/PBO 严谨度闸 + 诚实基准。**

## 二、正方:为什么"看起来能赚"

1. **回测诚实度高**:次日 open 成交、A 股全成本(佣金万2.5+下限5、印花税 2023-08-28 前后 0.1%→0.05% 历史感知、过户费、平方根冲击滑点)、paper≡live 同一条成交路径。结论可信度远超多数开源框架。
2. **回撤控制是真的**:ATR 止损 + -30% 组合熔断 + 软保护(连损锁 `sg`、回撤锁 `md`)。尾部被管住,不是裸奔。
3. **选池 beta 是真实收益来源**:ADV100 大盘 tilt 在 2024-01 微盘踩踏里 -14% vs ADV1000 -31%,尾部保护有效(`breadth_regime.py`)。
4. **工程可实盘**:QMT 接线 + 盘中守护 + 状态卡,不是玩具。

## 三、反方:为什么"不能稳定赚钱"

1. **核心杀手:没有任何已证 alpha。** 我自己在 `runtime.py:562-570` 写下的验证结论:
   > "整个因子层在 pool equal-weight OOS 下完全输给被动等权。截面内没有锐角可磨(within-pool alpha → 0)... 融合/阈值/行业限额全是纯 live-only 逻辑,零回测 PnL 证据。"
   - 13 个因子(动量/价值EP/质量/低波/规模…)在 ADV-topN 池内 OOS **输给等权**,只改排序不改收益。
   - 融合参数(`factor_blend=0.5`、`threshold=0.30`、`sentiment`)**从没被回测过**——决定实盘买什么的逻辑零 PnL 证据。
   - 10 个策略的选择基于 3 折 × ~14 交易日 OOS 小样本 Sharpe,统计功效不足以区分真本事和运气(已加 `_MIN_OOS_TRADES=10` 防护,但小样本本质未变)。
2. **"收益"= 押 regime,不是可复制 edge。** ADV100/1000 的收益排序**跨 regime 翻转**(小盘期 vs 大盘修复期),保大盘默认是 regime 押注。A 股 beta 本身不稳定:指数十年原地踏步 + 深度回撤。
3. **A 股微结构对 long-only 散户系统是结构性逆风**:T+1 锁流动性、涨跌停封单卖不出、卖出印花税+双边佣金。**高换手 edge 被成本吃光**——这正是散户"反转/择时"策略活不下来的原因。
4. **无 DSR/PBO 时,任何"跑赢"都可能是多重检验的运气**(本次已补这道闸,见下)。

## 四、裁决:用成熟量化系统的标准看

没有任何成熟机构声称 **long-only 股票 beta 能"稳定赚钱"**。稳定来自五件事,对照本系统:

| 成熟系统的稳定来源 | 本系统 | 差距 |
|---|---|---|
| 分散(几十上百条弱相关下注) | 单边 long-only 股票,高度同 beta | 大 |
| 低成本 | ✅ 成本模型完整、可低换手 | 小 |
| 风险目标 / 回撤控制 | ✅ 止损+熔断+软保护 | 小 |
| 不过拟合(DSR/PBO 闸) | 本次补上 | 已补 |
| **市场中性(long-short 去 beta)** | ❌ A 股做空受限(融券稀缺贵、股指期货有基差+门槛) | **结构性无解** |

**关键**:A 股散户现金账户 **无法做市场中性** → 收益必然带满 beta → "稳定(低回撤+持续正)赚钱"在数学上不成立。能诚实交付的不是"稳定赚钱",而是**"把 beta 收割得更省成本、更低回撤、不被过拟合骗"**。

## 五、那到底该做什么?—— 候选系统与严格验证

方法:修好的引擎(次日 open/T+1/全成本),窗口 2021-08~2026-06(59 个月,IS 前 34 / OOS 后 24,分界 2024-07),每个候选都过 IS/OOS + DSR/PBO 闸。

### 5.1 诚实基准(`scripts/baseline_returns.py`,月度调仓等权)

| 池 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| **全市场(~5500)** | **+10.49%** | **0.55** | **-24.5%** |
| ADV1000 | -2.51% | 0.02 | -53.5% |
| ADV300 | -5.33% | -0.08 | -60.0% |
| **ADV100(生产默认)** | **-3.24%** | 0.02 | **-58.3%** |

(这复现了 memory 里"被动等权 5y ≈ +11.78%"的孤值:全市场等权年化 +10.49%。)

### 5.2 候选 A:趋势去风险叠加(`scripts/candidate_stability.py`)—— 被闸否决

在池净值上加趋势滤网(净值跌破自身 W 月均线则空仓)。天真看很诱人(ADV1000 上 W=10 → 全期 +22% vs base -11.6%),但:
- 相邻窗口收益剧烈翻转(W6 +11.8% / W7 -1.6% / W8 -11% / W10 +22%)= 过拟合特征;
- **DSR=0.49**(观测夏普 0.092 < 多重检验基准 0.094)、**PBO=0.57~0.74**(>0.5,比抛硬币还差);
- 叠加**只机械削回撤**(-53%→-30%),**不产生 alpha**;OOS 反而跑输 base(修复期空仓踏空)。

**裁定:择时叠加不是可部署 edge,是曲线拟合。闸拦住了它。**

### 5.3 候选 B:放开选池宽度(`scripts/breadth_alpha.py`)—— regime 押注,非稳定 beta

全期看"越宽越好"(全市场 +10.49% > ADV100 -3.24%),但按时间切开就翻脸:

| 池 | IS 年化(21-08~24-07) | OOS 年化(24-07~26-06) |
|---|---|---|
| 全市场 | -4.80% | +36.43% |
| ADV100(默认) | **-26.23%(最差)** | **+42.10%(最好)** |

**宽度收益排名 IS/OOS 完全翻转**——全期优势全来自 2021-2024 的小盘 regime,最近两年大盘反而领先。文献印证(Liu-Stambaugh-Yuan 2019 JFE):A股 size premium 真实但**大半来自"壳价值"**(底部 30% 票约 40% 市值是壳期权),作者构造干净因子时**刻意剔除最小 30%**;注册制/退市正抽掉这块地基(小盘 2005-16 年化 +10% → 近 2019 -19%);2024-02 中证2000 单月 -32.8% 纯流动性踩踏需国家队救。**放宽宽度纳小盘 = 押注一个正在衰弱的壳价值溢价 + 肥流动性尾部。**

补充冷峻点:在**可交易范围内**(ADV100~1500)放宽宽度几乎不帮忙(夏普 0.02→0.07,回撤都卡在 -50~58%)。全市场那 -24.5% 低回撤主要靠**不可交易的微盘尾部**分散 + 0.3% 成本没算微盘持仓价差/冲击撑出来的。

> 唯一稳健(非 regime)的效应是**分散化**:全市场夏普 0.55 vs ADV100 0.02(PBO=0.005 支持其夏普稳健)——但这是分散降低特质风险,不是收益 edge。

### 5.4 候选 C:防御性因子低换手倾斜(`scripts/defensive_tilt.py`)—— 风险调整后能否稳健改善

低波/质量/价值EP/股息,ADV1000 池月度调仓,对照同池等权,看**夏普 IS&OOS 是否双超基准 + DSR/PBO**。

| 变体 | 全期夏普 | 最大回撤 | IS 夏普超基准? | OOS 夏普超基准? |
|---|---|---|---|---|
| 同池等权(基准) | 0.02 | -53.6% | — | — |
| 低波 top50 | 0.09 | **-31.5%** | ✓ | ✗ |
| 质量 top50 | 0.09 | -60.5% | ✗ | ✓ |
| 价值EP top50 | 0.03 | -44.0% | ✓ | ✗ |
| 防御四合一 top50 | -0.07 | -37.5% | ✓ | ✗ |
| 防御四合一 top100 | 0.13 | -36.6% | ✓ | ✗ |

- **没有一个变体在 IS 和 OOS 双半程都跑赢基准夏普**(每个都一半 ✓ 一半 ✗ = regime 翻转,和宽度一个病)。
- **过拟合闸否决**:先验四合一 top50 **DSR=0.366**(观测每期夏普竟为负 -0.020 < 基准 0.026)、挑最优 top100 DSR=0.537(都远低于 0.95)、**PBO=0.491**(≈抛硬币)。

**裁定:防御因子倾斜不产生稳健的风险调整后 alpha。** 但浮现一个真实、机械、非 regime 的效应:**低波 top50 把回撤从 -53.6% 削到 -31.5%**(所有防御变体回撤都更浅),两个半程都成立——低波不多赚钱,但机械降回撤(牛市少赚为代价)。

### 5.5 小结:穷尽了 long-only 可交易杠杆,收益杠杆全军覆没

| 杠杆 | 结果 | 闸判 |
|---|---|---|
| 选股/因子融合 | within-pool alpha ≈ 0 | 无超额 |
| 择时(趋势叠加) | DSR 0.49 / PBO 0.57~0.74 | **过拟合** |
| 选池宽度(小盘 beta) | IS/OOS 排名翻转 | **regime 押注** |
| 防御因子倾斜 | 无变体双半程超基准,DSR 0.37 / PBO 0.49 | **过拟合** |

**在 long-only 内**,唯一稳健(非 regime、可复制)的效应全是降风险的:分散化(宽 → 夏普↑)、低波/趋势/熔断(→ 回撤↓)。**没有一个能产生 alpha。**

### 5.6 候选 D:市场中性 long-short(`scripts/neutral_longshort.py`)—— 唯一碰到真 alpha 的方向,但 OOS 已失效

用户决策树里点出的唯一能"去 beta 才可能稳定"的方向,也是前面全没测过的:池内因子有真实 IC(低波 0.098/低换手 0.094/反转 0.076 OOS),而 **long-only 吃不到空头腿**。做美元中性 L/S(多顶部 20% / 空底部 20%)按构造去掉 beta,理论上能收割全 IC。

| IC三合一 L/S 口径 | 全期年化 | 全期夏普 | IS 夏普 | **OOS 夏普** |
|---|---|---|---|---|
| raw 理论(仅交易成本) | +17.45% | **1.02** | 2.29 | **−0.21** |
| 融券 8%(个股空头,可执行) | +8.49% | 0.56 | 1.73 | **−0.63** |
| 期指对冲(多头篮子 − IC/IM,基差 6%) | −1.96% | −0.26 | 1.23 | −1.71 |

- **中性 L/S 确实碰到了真 alpha**:raw 夏普 1.02、扛过 8% 融券费仍 +8.5%/夏普 0.56——远超任何 long-only,证实"long-only 把空头腿 alpha 留在桌上"的判断。
- **但 OOS 是杀手**:全期正收益**全来自 2021-2024**(IS 夏普 2.29);**所有变体最近两年 OOS 夏普转负**(因子拥挤 + 小盘 regime 结束,价差反转/死掉)。闸:DSR 0.682 / PBO 0.402(随机块看还行,但按时间顺序 OOS 才是诚实检验——负的)。
- **可执行性**:A 股融券稀缺——借不到因子最想空的小盘垃圾股;唯一无需融个股的期指对冲版(多头超额薄 − 基差)是**负的**。

**裁定:市场中性是唯一碰到真 alpha 的方向,但 edge 已在最近两年 OOS 失效 + A 股做空摩擦吃光可执行版 → 当下不可部署。** 若有机构融券准入并要追:只能当**正在衰减的 edge**——小仓位、滚动 DSR/PBO 监控、OOS 一转负立即停。

### 5.7 小结:long-only 与市场中性都测遍了

| 方向 | 有没有真 alpha/稳定收益 | 能不能现在稳定赚钱 |
|---|---|---|
| long-only 股票:选股/择时/宽度/防御 | 否(池内 α≈0) | 否(全被闸否决) |
| 市场中性 L/S | 是(历史夏普~1.0) | 否(OOS 已失效 + 融券稀缺/基差吃光) |
| **可转债(跨资产)** | **是——结构性稳定 beta(非 alpha)** | **相对可以:结构性最稳的 long-only 载体** |

### 5.8 候选 E:可转债 —— 跨出股票边界后,找到了

股票 long-only 的死结是"beta 去不掉、且股票 beta 不稳"。**换一种 beta 就行**:可转债 = 债底(到期还本)+ 转股期权,天然是"股性上行 + 债性保底"的**不对称收益**,是 A 股结构性最稳、且 **long-only 无需融券** 的方向。用 akshare 拉全量可转债日线(`scripts/fetch_convertibles.py` → `data/cb.db`,997 券/748k 行/含 690 只已退出券=**幸存者正确**,违约左尾在:搜特 128100 崩到 18)+ `scripts/cb_lowprice.py` 回测:

| 策略(2018–2026,102 月,含 2018/2022 两次熊市) | 年化 | 夏普 | 最大回撤 | IS 夏普 | OOS 夏普 |
|---|---|---|---|---|---|
| **全等权可转债(beta)** | **+10.25%** | **0.85** | **−18.6%** | 1.00 | 0.63 |
| 低价 top30(双低核心) | +11.48% | 0.82 | −21.0% | 1.23 | 0.56 |
| 低价 top40 | +11.45% | 0.88 | −18.0% | 1.20 | 0.62 |

- **可转债 beta 本身就稳**:8.5 年跨两次熊市 +10.25%/年、夏普 0.85、回撤仅 −18.6%,**IS/OOS 双半程都正**——远胜任何股票策略(股票 beta 夏普 ≤0.55、回撤更深、regime 翻转)。债底给了股票没有的下行保护。
- **低价"双低"倾斜不是稳健 edge**:全期跑赢 beta,但 **PBO=0.758(选变体过拟合)**、OOS 夏普不及 beta(2024 违约潮砸低价券)。→ **价值在可转债 beta 本身,不在倾斜。**

**裁定(初判):这是搜索的正面答案——A 股能相对稳定赚钱的 long-only 载体不是股票、是可转债。** 但仍是 beta 不是 alpha。**这个初判随后被多 agent 对抗式验证如实压回地面,见 §5.9。**

### 5.9 多 agent 对抗式验证:数据可信,但"稳定赚钱"是叙事过拟合

6 个红队各攻一个失效面(全部实际查证 cb.db / 调 akshare / web / 自写脚本重算)+ 首席裁判综合。诚实的 10 年口径先修正为 **全等权 +7.57%/yr(2016 起),不是 +10.25%(2018 起,有起点依赖)**。

| 对抗维度 | 裁决 | 关键证据 |
|---|---|---|
| 数据可信度/幸存者 | ✅ 站得住 | 33 只 fetch 失败全在窗外/去重,**无窗内违约券被删**;违约左尾在库(搜特→18/蓝盾→27);与官方中证转债指数月度相关 **0.909** |
| 复权/票息口径 | ✅ 保守 | akshare 是净价、漏票息 → 真实全收益反而 **高约 0.8~1.5%/yr**(低估),无假跳变 |
| 强赎/退出结算 | ⚠️ 轻微高估 | last-price 让退出券隐性多吃一个月池均值;强制 0% 结算 → +7.57%→**+5.49%**(−2.1pp),但夏普/回撤几乎不动。与漏票息大致对冲,净数据偏差 ±1pp |
| **过拟合/统计** | ❗**叙事过拟合** | **剔 2019/21/25 三大年 → CAGR 塌到 +0.74%/夏普0.12,12 年 6 年负**;edge ≈100% 来自 3 个不可预期牛年;起点 2015 → 回撤其实是 **−48.5%**(−18.6% 是 2018+ 被洗过的);低价倾斜 PBO 0.63~0.76 确定过拟合,禁用 |
| **前瞻/regime** | ❗**不可外推** | 当前估值历史极贵端(中位价 130、双低池仅 5 只);2024 违约潮结构性削弱债底;可交易券 535→309(**−42%**,"宽度"叙事夸大 2-3x);利率 re-rating 已耗尽(10Y 1.74%,6 分位) |
| 成本/容量 | ❗**容量墙** | 剔 <1000万/日流动性券后收益转负;**容量墙 ~1~3 亿**,超过即抽走全部 edge |

**裁判终判**:
- **过拟合**:全等权 beta 不是曲线过拟合(无可调参),但是 **regime 依赖的"假稳定"**——"稳"是叙事过拟合;低价倾斜是真过拟合,禁用。DSR 0.982 被正确降级为"纯 PSR(SR>0)",不能当抗过拟合证据。
- **数据可信**:cb.db 可信(0.909 相关、幸存者零偏差、违约左尾在),净偏差 ±1pp 内,不推翻正收益。
- **"稳定"重定义**:"每年正"证伪(6/12 年负);唯一站得住=**成熟期(2018+)、持有 ≥2 年、回撤可控**(滚动 24 月 84% 为正、最差 −17%)。
- **现实前瞻**:小资金(≤3000万)**+3%~+6%**(中枢 ~+4.5%);大资金(≥3亿)**−1%~+3%**(可执行核心是负);理性锚定官方指数 +5.5% 或更低,别外推夏普 0.67。
- **一句话**:能不能赚不取决于策略,取决于你搬多少钱进那条买不动的薄券长尾。**结论:不值得为这点被动 beta 冒违约+容量+regime 三重险——被动持有官方可转债指数(如中证转债/可转债 ETF)更省心、更可执行。**

## 六、最终结论 + 交付的系统

### 6.1 结论:股票 long-only 稳定赚钱不可能(恒等式);但换到可转债,找到了

**股票这套系统 = 不可能**——这是恒等式不是策略缺陷:

穷尽搜索 **long-only(选股/择时/宽度/防御因子)与市场中性 long-short 两个方向**(全部修好引擎 + IS/OOS + DSR/PBO)后,**没有一个能在当下稳定赚钱**:

> **long-only**:净值 = 选池 beta + 池内 alpha。池内 alpha ≈ 0(已证);beta 无法对冲(A 股融券稀缺贵、股指期货有基差+门槛,散户现金账户做不了市场中性)→ 净值 = beta,A 股 beta 不稳定 → 结构上不可能稳定。**这是恒等式。**
>
> **市场中性 L/S**:能去掉 beta、且**确实碰到真 alpha**(历史 raw 夏普 1.02、扛过 8% 融券费仍 +8.5%)——但 **edge 已在最近两年 OOS 失效**(因子拥挤/regime 结束),且 A 股融券稀缺(借不到想空的小盘)+ 期指对冲基差吃光可执行版 → **当下不可部署**。是"曾经有效、正在衰减、且受做空约束"的 edge,不是可托付真钱的稳定系统。

**但换一种 beta 就成立**:可转债的债底让"净值 = beta"里的那个 beta 变成有下行保护的不对称 beta——8.5 年 +10.2%/年、夏普 0.85、回撤 -18.6%、IS/OOS 双半程都正(§5.8)。这是搜索找到的、最接近"A 股稳定赚钱的 long-only 系统"的答案:**不是 alpha,是一个结构上更好的 beta。**

所以本次交付两件事:(a) 对股票这套系统——一套**让你不亏在"自以为有 edge"上、把 beta 收割得省成本低回撤**的纪律框架(DSR/PBO 闸 + 诚实基准 + 现实预期);(b) 指出真正该走的路——**把系统扩到可转债**(数据管道已备好 `data/cb.db`,回测已证)。

### 6.2 交付物

1. **DSR/PBO 严谨度闸**(`quanti/backtest/overfit.py`,已提交,自检通过):任何新因子/策略/参数上线前必须过 **DSR≥0.95 且 PBO≤~0.2**。本次它已当场拦下 3 个天真回测会让你上线的伪 edge(择时叠加/宽度/防御因子)。
2. **可复现的诚实基准**(`scripts/baseline_returns.py`):以后任何"系统"都要先赢过全市场等权(5y +10.49%),否则没资格动真钱。
3. **三个验证脚本**(候选/宽度/防御):把"没 alpha"从口头结论变成可复跑的证据。

### 6.3 现实配置建议(基于证据,非 regime 押注)

- **降低预期**:目标不是绝对收益或"稳定盈利",而是**风险调整后 ≈ 分散化市场 beta,把最大回撤和过拟合风险摁住**。熊市必然回撤,接受它。
- **两个稳健可用的降风险杠杆**(它们不多赚钱,只让曲线更平——值不值看你的风险偏好):
  - **分散**:持仓只数尽量多(降特质风险,全市场夏普 0.55 vs ADV100 0.02);
  - **低波倾斜 / 组合熔断**:低波 top50 把回撤 -53.6%→-31.5%(两半程都成立);系统已有的 -30% 熔断 + ATR 止损保留。
- **明确不要做的**:别追因子 alpha、别择时押 regime、别把默认选池赌在小盘宽度上(壳价值溢价正被注册制/退市抽掉地基 + 肥流动性尾部,2024-02 中证2000 单月 -32.8%)。当前 `no_screener_take=100` 大盘默认**不是"尾部保护"**(全周期它回撤最深),但它可交易;若放宽宽度,必须当作**带尾部风险的风格敞口显式限额**(小微盘≤组合 20%、剔除最小 30% 壳票、成交额下限 + 面值临界 fail-loud 过滤),并先过 DSR/PBO 闸。

### 6.4 固化:推荐的"被动 beta + 风控"基线配置(可复制)

用户拍板方向 = 接受结论、固化被动+风控基线。以下是**可直接照抄的 `goal.params`**(参数名已对当前代码核实),配套风控已是默认值,无需改代码——把系统当"纪律化 beta 收割机"用,而不是 alpha 机器。

```jsonc
{
  "agent_mode": "ensemble",     // 规则集成,不用 llm(LLM 无已证 alpha)
  "equal_weight": true,         // 等权持有 → 分散,唯一稳健抬夏普的杠杆
  "max_holdings": 0,            // 0=不砍持仓数 → 尽量分散(降特质风险)
  "no_screener_take": 100,      // 保持大盘默认=可交易;放宽宽度是 regime 押注,别赌
  "factor_blend": 0.0,          // 不混因子(池内 alpha≈0,融合参数未过闸)
  "sentiment_enabled": false,   // 情绪层无回测证据
  "use_generated_factors": false, // 生成因子须先过 DSR≥0.95/PBO≤0.2 才开
  "rotation_enabled": false,    // 换仓 opt-in,默认关
  "llm_debate": false
}
```

风控基线(已是 `RiskConfig`/`ProtectionConfig` 默认,确认开着即可):`portfolio_stop_loss_pct=-0.30`(组合熔断)、`atr_stop_k=2.0`/`atr_stop_n=14`(ATR 止损)、`stop_loss_pct=-0.15`(绝对地板)、`max_position_pct=0.10`+`max_industry_pct=0.30`(post-trade 强制)、protections 的 `stoploss_guard`+`max_drawdown` guard(连损/回撤锁)。

**如实预期**:这套 = 捕获 A 股大盘 beta + 硬风控,**没有 alpha**。收益随 beta regime 走(全周期基准 ADV100 约 -3%/年、近两年修复期 +42%),价值在于**回撤和过拟合风险被摁住、成本低、行为可解释**。想要更平的曲线可加**低波倾斜**(已验证把回撤 -53.6%→-31.5%,两半程都成立),但需把因子配置接成低波单因子(见 6.5,当前 `factor_blend` 走的是全 13 因子 composite,不等于低波)——属小改动,别当现成开关。

### 6.5 建议的后续代码改动(本次未贸然改动线上热路径)

1. **DSR/PBO 闸接进 StrategySelector / LLM 因子挖掘采纳门**:当前 selector 按 OOS 夏普(3 折 ~14 交易日小样本)给资本权重,应叠加"用候选数 N 对赢家夏普做多重检验紧缩(DSR),不过阈值退回等权"——直接根治审计里"选择是噪声"的病。涉及注解校准(年化 vs 每期夏普、小 T),留独立改动谨慎验。
2. **低波单因子倾斜作为可选风控**:6.4 提到的低波降回撤(-53.6%→-31.5%)需要一个"只用 `realized_vol_20d`(或低波+低换手)的 `FactorConfig`"接口,让 `factor_blend` 能指向它而非全 13 因子 composite。这是**降风险**选项(非 alpha),小改动,先过 DSR/PBO 的回撤/夏普双核再默认化。
