# 任务：打新增强研究（IPO overlay on sse_enhance）

## 背景（先读）

- 存活策略：`strategies/sse_index_enhance.py`（PR #197）——复制沪市总市值加权
  指数，结构性跑赢上证综指。持仓天然满足**沪市打新市值门槛**（T+2 前 20 日
  日均沪值 ≥1 万，每 1 万 = 1000 股额度）。
- 已证否清单见 docs/2026-07-01-can-this-system-make-money.md。**打新是清单外
  唯一剩下的、长仓可做、结构性正期望的收益源**（发行定价受 23 倍市盈率窗口
  指导 → 一级市场限价 → 二级市场首日溢价，是制度价差不预测能力）。
- 2026-09-11 主编快速实测（tushare new_share × 本地 market.db）：2024H1 主板+
  创业板+科创板 43 只有行情样本，**首日开盘均 +123.2%、收盘均 +128.2%**。
  但这是发行收紧后的单边窗口，禁止直接外推。
- `new_share` 接口有 `ballot` 字段（中签率），配合申购额度可算**期望收益**，
  不需要 Monte Carlo。

## 要做什么

### 第一步：无策略依赖的估计器 `scripts/ipo_yield_study.py`

输入：沪市账户市值档位（10/30/50/100/500 万）。数据：tushare
`new_share`（start_date=20180101 分页拉全）+ 本地 `data/market.db` 首日行情
+ `daily_basic`/`stocks` 判定板块。对每只新股：

1. 可申购额度 = min(市值/1万×1000, 网上发行量×千分比上限)。沪深规则不同：
   沪市每 1 万市值 1000 股，深市每 5000 市值 500 股；额度上限≈网上初始
   发行量的千分之一。北交所打新需全额资金预缴，**排除**（写明）。
   科创板需开通权限（50 万门槛账户才有），单独一档处理。
2. 期望中签股数 = 申购股数 × ballot（用接口返回的真实中签率）。
3. 每股期望利润 = 首日开盘卖出（T+2 晚间中签、T+4 首日卖出不可能——
   **实际规则：新股上市日即签购结果已缴款，首日即可卖**，故用首日开盘价；
   一字板卖不出：`open == high == low == close` 或 44% 顶格时按次日开盘计）。
   破发按实际亏损计（2022-2023 注册制破发潮必须进样本，不许截断）。
4. 年化增强 = Σ利润 / 档位市值，**逐年**报告（2018-2026），并标注
   2023-08 后暂停、2024 重启后的结构性变化。

### 第二步：策略叠加 `strategies/sse_ipo_overlay.py`

仅当第一步证明：档位 50/100 万下，**近 5 年逐年增强 > 0 且最差年
> +0.5%/年**，才写这个策略——它包一层 sse_enhance 权重信号 + 新股申购/
首日卖出模拟（PaperBroker 路径），回测口径与 sse_enhance 对账。达不到
阈值就停在这一步，写研究文档收尾。

### 第三步：研究文档 `docs/2026-09-11-ipo-overlay.md`

结论必须诚实回答：(a) 打新增强是不是 regime 依赖（2023-02~2024-08 发行
收紧期的样本处理要明示）；(b) 逐年分解 2018-2026，特别标注 2021-09~2022
破发潮的负贡献（不许用均值掩盖，给分位数）；(c) 对 sse_enhance
持有人的现实预期（元/年/百万市值，最差年而非均值）。
