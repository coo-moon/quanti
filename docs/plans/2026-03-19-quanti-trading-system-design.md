# Quanti - A股量化交易系统设计文档

**日期**: 2026-03-19
**状态**: 已批准

## 概述

从零搭建一个面向中国A股市场的量化交易系统，支持从回测到实盘的全流程。系统采用 Python 全栈方案，支持多种策略类型（趋势/动量、多因子选股、统计套利），提供 Web 仪表盘进行监控和管理。

## 技术选型

- **语言**: Python 3.11+
- **后端框架**: FastAPI
- **前端框架**: Vue 3 + ECharts
- **数据库**: SQLite（起步）→ PostgreSQL（进阶）
- **数据源**: AkShare（免费）→ Tushare Pro（付费）
- **核心库**: pandas, numpy, ta-lib

## 系统架构

```
数据获取 → 数据存储 → 因子引擎 → 策略引擎 → 回测引擎
                                        |
                        风控模块 ← 交易执行 ← 信号生成
                                        |
                                   Web 仪表盘
```

### 模块清单

| 模块 | 职责 | 关键技术 |
|------|------|----------|
| 数据获取 | A股行情、财务、基本面数据采集 | AkShare → Tushare Pro |
| 数据存储 | 本地持久化，统一数据接口 | SQLite → PostgreSQL |
| 因子引擎 | 技术指标、基本面因子计算 | pandas + ta-lib |
| 策略引擎 | 策略定义、信号生成 | 自研框架，插件式策略 |
| 回测引擎 | 历史模拟、绩效评估 | 事件驱动回测 |
| 风控模块 | 仓位管理、止损止盈、风险指标 | 独立风控层 |
| 交易执行 | 模拟盘/实盘下单 | 统一交易接口 |
| Web 仪表盘 | 策略监控、回测可视化、管理 | FastAPI + Vue 3 |

## 模块详细设计

### 1. 数据获取与存储

**数据类型**:
- 日线行情：开高低收、成交量、成交额、换手率
- 分钟线行情：1分/5分/15分/30分/60分K线
- 基本面数据：PE、PB、ROE、营收增长率等财务指标
- 板块/行业数据：申万行业分类、概念板块
- 指数数据：沪深300、中证500等基准指数
- 复权因子：前/后复权价格计算

**数据源策略**（渐进式）:
1. 起步：AkShare（完全免费，无需注册）
2. 进阶：Tushare Pro（数据更稳定、字段更丰富）
3. 通过适配器模式封装，切换数据源不影响上层代码

**核心表设计**:
- `stocks`: 股票基本信息（代码、名称、上市日期、行业）
- `daily_quotes`: 日线行情数据
- `minute_quotes`: 分钟线数据
- `financials`: 财务报表数据
- `factors`: 计算后的因子值缓存
- `trade_calendar`: 交易日历

**关键设计点**:
- 增量更新：每次只拉取新数据
- 数据校验：检测缺失交易日、异常价格
- 统一接口：上层通过 DataProvider 读取数据

### 2. 因子引擎

**因子分类**:

技术因子:
- 趋势类：MA、EMA、MACD、布林带
- 动量类：RSI、KDJ、威廉指标
- 成交量类：OBV、量比、资金流向
- 波动类：ATR、历史波动率

基本面因子:
- 估值类：PE、PB、PS、PEG
- 盈利类：ROE、ROA、毛利率、净利率
- 成长类：营收增长率、净利增长率
- 质量类：资产负债率、现金流/净利润

复合因子:
- 用户可组合多个基础因子
- 因子标准化（Z-score、排名百分比）
- 因子中性化（行业中性、市值中性）

**设计要点**:
- 注册机制：因子通过装饰器注册
- 缓存：计算结果存入 factors 表
- 批量计算：支持全市场截面计算

### 3. 策略引擎

**策略接口**:

```python
class BaseStrategy:
    def init(self, config: dict):
        """初始化策略参数"""

    def on_bar(self, bar: BarData) -> list[Signal]:
        """每根K线触发，生成交易信号"""

    def on_factor(self, factors: pd.DataFrame) -> list[Signal]:
        """因子截面数据触发（用于多因子选股）"""
```

**策略类型**:
- 择时策略：on_bar 逐K线驱动
- 选股策略：on_factor 截面数据驱动
- 组合策略：多策略组合

**信号定义**:

```python
@dataclass
class Signal:
    stock_code: str      # 股票代码
    direction: str       # "buy" / "sell"
    strength: float      # 信号强度 0-1
    reason: str          # 信号原因
```

**策略管理**:
- 热加载：strategies/ 目录下自动识别
- 参数化：YAML 配置，支持参数优化扫描
- 版本管理：策略变更可追溯

### 4. 回测引擎

**架构**: 事件驱动（回测和实盘复用同一套策略代码）

**A股特殊规则处理**:
- T+1 交易
- 涨跌停限制：普通股 ±10%，ST股 ±5%，科创板/创业板 ±20%
- 最小交易单位：100股
- 手续费：佣金 + 印花税（卖出千1）+ 过户费
- 复权处理
- 停牌处理

**绩效评估指标**:
- 收益指标：总收益率、年化收益率、月度收益
- 风险指标：最大回撤、年化波动率、下行风险
- 风险调整：夏普比率、索提诺比率、卡尔马比率
- 交易统计：胜率、盈亏比、平均持仓天数、换手率
- 基准对比：超额收益、信息比率

**回测输出**:
- 净值曲线（与基准对比）
- 月度/年度收益热力图
- 持仓明细和交易记录
- 绩效报告（可导出 HTML/PDF）

### 5. 风控模块

**仓位管理**:
- 单只股票最大持仓比例（默认 10%）
- 单行业最大持仓比例（默认 30%）
- 总仓位上限（默认 80%）

**止损止盈**:
- 个股止损线（默认 -8%）
- 个股止盈线（可配置）
- 组合整体回撤止损（默认 -15%）

**交易限制**:
- 单日最大交易次数
- 单日最大交易金额
- 禁止交易名单（ST股、新股等可配置）

**设计要点**:
- 独立拦截层，在信号→下单之间执行
- 所有规则可通过配置文件调整

### 6. 交易执行模块

**执行模式**:

模拟执行器:
- 按收盘价/次日开盘价成交（可配置）
- 模拟滑点（默认 0.1%）
- 模拟部分成交
- 完整订单日志

实盘执行器（预留接口）:
- 统一抽象层 BrokerAdapter
- 后续可实现具体券商适配器
- 订单状态跟踪

**订单定义**:

```python
@dataclass
class Order:
    stock_code: str
    direction: str       # "buy" / "sell"
    quantity: int         # 股数（100的整数倍）
    price_type: str       # "market" / "limit"
    limit_price: float
    status: str           # "pending" / "filled" / "partial" / "cancelled"
    strategy_name: str
```

### 7. Web 仪表盘

**技术方案**:
- 后端：FastAPI（REST API + WebSocket）
- 前端：Vue 3 + ECharts
- 认证：简单本地认证

**页面规划**:

| 页面 | 功能 |
|------|------|
| 总览仪表盘 | 账户总览、持仓概况、今日盈亏、策略运行状态 |
| 回测中心 | 选择策略→配置参数→运行回测→查看结果 |
| 策略管理 | 策略列表、启停控制、参数配置、运行日志 |
| 持仓明细 | 当前持仓、盈亏分析、行业分布 |
| 交易记录 | 历史交易流水、按策略/股票筛选 |
| 数据管理 | 数据更新状态、手动触发数据同步 |

**实时推送**:
- 策略信号通知
- 持仓盈亏实时更新
- 异常告警（风控触发、数据异常）
