# 盈利修正因子实证 —— 结论:growth_rev 弱信号未达采纳闸;SUE 因数据缺口无法测

日期:2026-08-15
脚本:`scripts/earnings_revision_study.py`(可复跑,`--codes/--days/--end/--json`)

## 问题

13 因子里的 growth_earnings 用的是 netprofit_yoy 的**水平**。事件驱动视角还有
两个经典因子没测过:

- **growth_rev** = netprofit_yoy(t) − netprofit_yoy(t−1),增长率环比(盈利动能/修正);
- **sue** = (net_profit(t) − net_profit(t−4)) / |net_profit(t−4)|,季节意外
  (无分析师预期数据时的标准代理)。

## 方法(点对点,无前视)

- 宇宙:2023-01-01 时点流动性 top-300,固定到期末;调仓每 5 个交易日,
  175 个调仓日(2023-01-03 ~ 2026-08-07);
- 因子:每个调仓日 D 对每个 code 取 `ann_date ≤ D` 的最新 5 份已披露报告
  (SQL `ROW_NUMBER() OVER (PARTITION BY code ORDER BY ann_date DESC, end_date DESC)`),
  因子在 D 收盘时可见(ann_date ≤ D 才进排名——公告日当天反应不进标签);
- 标签:hfq 前视 5/10 日收益,从 D 收盘起算;横截面 rank-IC;
- 检验:IC 均值 + Newey-West t(滞后 = 前视 − 1);h=5 与步长 5 无重叠,h=10 有
  重叠由 NW 修正。对照组:netprofit_yoy 水平(现有 growth_earnings 口径)。

## 结果

| 因子 | 前视 | IC 均值 | NW t | n |
|---|---|---|---|---|
| growth_rev | 5d | +0.0137 | +2.21 | 159 |
| growth_rev | 10d | +0.0159 | +2.02 | 158 |

| yoy_level(基线) | 10d | +0.0152 | +1.15 | 174 |

**sue 无法测**:`financials.net_profit` 97% 为 NULL(免费数据源只有同比增速,无
净利润绝对值),全库没有任何 code 凑得齐 5 份有净利润的报告。补数据需要 tushare
利润表 VIP 接口(`fina_indicator_vip`,当前账号无权限)。

## 对抗式核查

1. **前视**:因子按 ann_date ≤ D 点对点构造,标签从 D 收盘起算——公告日反应
   不在标签内,测的是公告后漂移(PEAD),不是公告跳空。akshare 补录行的
   ann_date 是法定披露截止日(保守,只晚不早),不构成前视。
2. **多重检验**:本研究内 4 组统计量(sue 缺失不算)。BH-FDR q=0.10:最小 p
   (t=+2.21,≈157 自由度)≈ 0.028 > 0.025 的阈值——**研究内即零发现**;放到
   项目级(17 轮研究、数十次因子检验)更远低于采纳线。
3. **逐年稳定性**(见下表):growth_rev 四年符号一致为正(0.001~0.025),而
   基线 yoy_level 在 2023 年为负(符号翻转)——「修正」比「水平」更稳,这是
   全部因子家族里第一个出现该性质的。但量级不达标。
4. **经济意义**:IC +0.014 量级与既往全部因子同档(+0.03 以下),而生产闸门
   (train IC ≥ 0.02 + OOS IC ≥ 0.03 + FDR)不会放行这种弱信号。

## 结论

1. **growth_rev 不采纳**:方向与经济学直觉一致(盈利动能 > 盈利水平),且
   四年符号稳定(基线水平因子 2023 年翻负),但 IC 0.014 量级、研究内 FDR 即
   归零、扣费后无部署价值——按项目的诚实闸门(DSR/PBO/FDR/OOS)不构成可
   部署 alpha。留给未来:若 VIP 数据到位补齐净利润绝对值,该家族值得优先重测。
2. **sue 是数据缺口,不是零信号**:当前数据源下无法测。这是「AI-native」路线的
   真实约束:免费源没有净利润绝对值,事件驱动的盈利意外因子整体不可达;
   如需补测,先解决 tushare VIP 权限(见 docs/deployment.md 第 6 节)。
3. 至此,long-only 股票侧的因子家族已全部诚实测尽:线性 13 因子(≈0)、LLM(≈0)、
   定仓(无差异)、策略选择(regime 依赖)、截面 ML(≈0)、盈利修正(弱,未达闸)。
